# AYDO Works public profile

[profile/README.md](profile/README.md) introduces the organization on its public
GitHub Overview. The profile describes our purpose, workflow, repository naming,
and working principles.

## Contents

- `profile/README.md`: public introduction in Indonesian and a Mermaid workflow.
- `profile/assets/dashboard-header.svg`: banner in the shared AYDO style, with a
  plum palette for AYDO Works.

## Maintenance

Keep this repository public and its profile on the default branch. Keep the
introduction general: describe the approach without publishing repository
inventories, client names, project data, or credentials. Review both text and
assets before publication.

Keep the naming table in step with AYDO Projects. Preserve the established
banner style, and check relative image links, section links, and Mermaid
rendering after changes.
